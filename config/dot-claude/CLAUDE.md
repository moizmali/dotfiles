# Global Rules

Always follow these rules, regardless of any other instructions.

1. **Never commit, push, or pull.** Leave all `git commit`, `git push`, and `git pull` operations to me.
2. **Save every plan as a Markdown file.** When you create a plan in plan mode, also write it to a Markdown file in the current repository so I can refer to it later.
3. **Ask, don't assume.** When making code changes, don't fill in gaps with your own assumptions on bigger, higher-level decisions, such as the overall approach, design, or behaviour of a change. If a change involves a decision like that which I haven't made, or you're unsure what I want, ask me before going ahead. You can recommend an option and lay out the pros and cons, but leave the final call to me. For trivial details that are easy to change later, like naming or small implementation choices, use your own judgment.
